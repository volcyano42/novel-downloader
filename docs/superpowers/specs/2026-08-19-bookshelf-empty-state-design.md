# 书架收藏空态返回入口修复 — 设计文档

> 日期：2026-08-19 ｜ 来源：16 项待办清单 D 组 #7
> 状态：已批准，进入实施

## 问题

`BookshelfPage.tsx` 中，收藏视图（`showFavoritesOnly=true`）在没有任何收藏书籍时，命中空态分支（第 195-196 行）：

```tsx
if (filtered.length === 0) {
  return <div>…"暂无收藏"…</div>;
}
```

该 `return` 发生在"全部/收藏"切换按钮组（第 218-227 行）**之前**，导致空态下按钮组不渲染——用户进入收藏视图后没有任何途径切回"全部"视图，被困在收藏空态。

## 方案

将"全部/收藏"切换按钮组**上移**到空态判断之前渲染，空态提示文本渲染在按钮组下方。空态与正常态共用同一组按钮：

```tsx
// 伪代码结构
<div className="space-y-6">
  <div className="flex items-center gap-3">
    {/* 全部 / 收藏 切换按钮（原 218-227 行，上移） */}
  </div>
  {filtered.length === 0 ? (
    <div>…空态文案…</div>
  ) : (
    <div>…分组渲染…</div>
  )}
</div>
```

- 空态文案逻辑不变（"无匹配结果" / "暂无收藏" / "书架空空"）
- 收藏无书时，用户可通过"全部"按钮返回书架

## 范围

- 仅 `frontend/src/features/bookshelf/BookshelfPage.tsx` 单文件，约 10 行重排
- 无后端改动、无新依赖、无测试框架改动

- 手动：书架无收藏时点"收藏"→ 空态下有"全部"按钮可返回
